## Public-repository policy

This repository stores Brad/OpenAI Android compatibility tooling, manifests, hashes, and documentation. It does not vendor the complete recovered third-party mod snapshots when the applicable redistribution terms have not been confirmed.

Mika's Mod Collection is published from a GPL-3.0 GitHub repository and its Nexus page also permits redistribution with creator credit. Balatro+'s upstream GitHub repository currently reports no repository license, so its recovered source is not republished wholesale here.

The exact recovered third-party snapshot can instead be kept in a private development repository or reconstructed locally from source files you are entitled to use.
